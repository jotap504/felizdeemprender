# V3 — experiencia interactiva FDE

- Mapa opcional de tres preguntas con acción inicial y derivación según etapa, dificultad y preferencia de acompañamiento.
- Ejemplos interactivos de las cuatro dimensiones, presentados como ejemplos del enfoque.
- Tres historias ampliadas con síntesis de testimonios existentes y videos originales. No se agregaron métricas ni intervenciones no documentadas.
- Hoja de trabajo descargable como TXT, sin registro ni persistencia de respuestas. Datos insertados como texto, sin HTML del usuario.
- Trazo animado de conexión, entradas al scroll y respeto por movimiento reducido. Tema oscuro heredado de v2.

Verificación: mapa (crecimiento/procesos/acompañamiento), generación de propuesta y activación de descarga en navegador móvil; sintaxis JS; archivos locales, videos, IDs y anclas. No se realizó una matriz exhaustiva de navegadores ni pruebas visuales automatizadas en modo oscuro.

V2 permanece sin cambios.
